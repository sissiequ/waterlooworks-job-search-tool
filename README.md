
# WaterlooWorks Job Search Tool
### CoopSync AI | EngHack 2026 — 1st Place

An AI-powered internship search, job matching, and resume optimization tool designed to help University of Waterloo students navigate the co-op application process more efficiently.

**Tech Stack:** Python, FastAPI, LLM APIs  
**Team:** 4 members  
**Project Initiator & Team Lead:** Sissie Qu

## Overview

WaterlooWorks Job Search Tool was created to simplify the process of finding relevant internship opportunities and tailoring resumes to job requirements.

The project uses AI to analyze resumes and job descriptions, identify relevant qualifications, and provide personalized job recommendations and resume improvement suggestions.

## Key Features

### 1. Resume Analysis
- Process resume content using LLM APIs.
- Extract skills, experience, and relevant qualifications.
- Organize unstructured resume information into structured data.

### 2. Job Description Analysis
- Analyze internship job descriptions.
- Identify required technical skills and qualifications.
- Extract information relevant to candidate matching.

### 3. AI-Powered Job Matching
- Compare candidate profiles with internship requirements.
- Identify relevant skills and experience.
- Generate personalized internship recommendations.

### 4. Resume Optimization
- Compare resume content against job requirements.
- Identify relevant qualifications to highlight.
- Generate AI-assisted resume improvement suggestions.

## Technical Implementation

- **Python:** Backend processing and data extraction.
- **FastAPI:** Backend API development.
- **LLM APIs:** Resume analysis, job description processing, and information extraction.
- **Semantic Matching:** Candidate and job requirement comparison.
